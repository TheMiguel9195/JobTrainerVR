# JobTrainerVR

**A VR-based job skills training platform developed with Unity.**

JobTrainerVR is a Final Degree Project focused on using Virtual Reality (VR) to support job skills training, autonomy, and social inclusion for people with intellectual disabilities.

The project provides interactive virtual workplace environments where users can practise basic job-related tasks in a controlled setting, with immediate feedback and simple interaction mechanics.

## Features

- **Virtual workplace environments:** Two training scenarios representing common workplace settings.
- **Supermarket training:** Practise restocking shelves by identifying missing products and placing items in their appropriate locations.
- **Office training:** Practise sorting documents by assigning them to the correct department and desk.
- **Interactive learning:** Grab and manipulate virtual objects using VR controllers.
- **Immediate feedback:** Audio feedback helps users identify correct and incorrect actions.
- **Locomotion options:** Support for continuous movement and teleportation to accommodate different user preferences.
- **Progress tracking:** Activity-specific mechanisms help users follow the training tasks.

## Repository Contents

This repository contains the C# scripts implementing the project's core logic, including object interactions, activity validation, task management, and user feedback.

It does **not** include the complete Unity project or all its assets, such as 3D models, textures, materials, and other third-party resources.

## Project Structure

The scripts cover the main systems used in the training environments, including:

- Product interaction and shelf validation.
- Supermarket activity and checklist management.
- Printer preparation and document generation.
- Document classification and placement validation.
- Audio feedback for user actions.

The scripts are intended to showcase the implementation of the project's main systems. They may depend on Unity components, scene objects, and Inspector configurations that are not included in this repository.

## Purpose

JobTrainerVR explores the potential of Virtual Reality as a tool for practising workplace tasks in a safe and repeatable environment. The project aims to contribute to the development of accessible training experiences that support autonomy and employment inclusion.

## Academic Context

This project was developed as a **Final Degree Project (TFG)** for the Bachelor's Degree in Computer Engineering at the University of Córdoba (Universidad de Córdoba), Spain.
